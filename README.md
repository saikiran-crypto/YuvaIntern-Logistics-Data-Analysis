# YuvaIntern – Logistics Data Analysis

## Project Overview

This project is part of the YuvaIntern Logistics Data Analyst Internship. It focuses on strategic planning and exploring logistics delivery performance and transportation costs using Python.

The project demonstrates how shipment data can be used to calculate key performance indicators (KPIs) and understand delivery performance.

## Objectives

* Calculate the on-time delivery rate.
* Calculate the delivery delay rate.
* Find the average delivery time.
* Calculate the average transportation cost.
* Determine the total shipment volume.

## Technologies Used

* Python 3
* Pandas

## Key Performance Indicators

| KPI                         | Description                                                |
| --------------------------- | ---------------------------------------------------------- |
| On-Time Delivery Rate       | Percentage of shipments delivered within the promised time |
| Delivery Delay Rate         | Percentage of shipments delivered later than promised      |
| Average Delivery Time       | Average number of days taken for delivery                  |
| Average Transportation Cost | Average transportation cost per shipment                   |
| Shipment Volume             | Total number of shipments analyzed                         |
